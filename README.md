# LibrarySystemV2
Bu proje; C# dilinde Nesne Yönelimli Programlama (OOP), LINQ (Language Integrated Query) sorguları, Event/Delegate (Olaylar) yapısı, Asenkron Programlama (async/await) ve JSON Dosya İşlemleri (System.Text.Json) gibi modern programlama kavramlarını pratik etmek için geliştirilmiş konsol tabanlı bir Kütüphane Yönetim Sistemidir.
